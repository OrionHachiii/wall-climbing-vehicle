# Contributing

Issues and pull requests are welcome for documentation corrections, reproducibility improvements, CAD export additions, safety improvements, and experimentally supported design changes.

Before contributing:

1. Do not upload course handouts, assignments, exams, grading material, or instructor-provided source files.
2. Identify the source and license of every added image, dataset, or design file.
3. Clearly distinguish measured results from estimates and third-party reference data.
4. Document hardware revisions with dimensions, material, manufacturing method, and test conditions.
5. Never commit personal credentials, private correspondence, or account-restricted files.

By contributing hardware-source changes, you agree that they are provided under CERN-OHL-S-2.0. Documentation contributions are provided under CC BY 4.0 unless clearly stated otherwise.
